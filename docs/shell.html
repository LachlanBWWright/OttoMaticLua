Level Editor API

These exported WASM functions can be called from the browser console or injected by your level-editor integration. The game also accepts ?level=N and ?terrain=PATH URL params to skip menus and load a specific level on startup.

OttoMatic_SetFenceCollisions(0 | 1)

Terrain Override

Path is resolved in the WASM virtual filesystem. Preloaded data lives under /Data/. To supply a custom terrain, load it via FS.writeFile() first, then call OttoMatic_SetTerrainPath.

Quick Reference

OttoMatic_SetFenceCollisions(0) — disable fence collisions (pass through fences)
OttoMatic_SetFenceCollisions(1) — re-enable fence collisions
OttoMatic_SetTerrainPath("/Data/Terrain/foo.ter") — override terrain file for current level
URL params: ?level=3 · ?terrain=/Data/Terrain/Custom.ter
